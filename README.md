1. Список участников команды - Кутяшов Алексей
2. Описание выбранной идеи решения
   Между пользователями есть переписки, у каждого участника переписки есть свой контейнер Chat со ссылкой на список сообщений этой переписки.
4. Описание пользовательских типов и функций в проекте
  В программе 4 класса:
    Message - хранит ссылку на сообщение, время отправления сообщения и имя отправителя.
    Chat - хранит ссылку на список сообщений одной из переписок и уведомление о новом сообщении.
        Создаётся парами, поэтому также хранит указатель на собеседника и итератор на Chat собеседника в его списке чатов.
        Исключение составляют общий чат и чат с самим собой, создающиеся по одиночке.
    User - хранит список ссылок на чаты(Chat) пользователя, логин, никнейм и пароль. Также хранит отдельно итератор на общий чат
        (ссылка на общий чат хранится в списке на ссылки всех остальных чатов пользователя), ссылку на себя на сервере и ссылку на сервер.
    Server - хранит ссылку на общий список всех создаваемых сообщений, два контейнера set для пользователей: в одном ссылки на пользователей
        отсортированы по их никнеймам, в другом по их логинам для поиска по никнейму и по логину соответственно. Также хранится
        ссылка на список сообщений общего чата, которая передаётся каждому новому пользователю.

   Основные методы классов:
      Chat coutChatHistory() выводит на консоль все сообщения переписки из списка сообщений;
      User showMyChats() выводит на консоль все переписки текущего пользователя (пока другому пользователю ничего не написать, переписки с ним нет);
      User createNewChat() создаёт Chat в список отправителю и Chat в список получателю;
      User sendMessage() добавляет сообщение в список сообщений, на который указывают каждый из двух Chat собеседников
                         и перемещает эти Chat в начало списков (таким образом первыми в списке чатов будут те чаты, в которых были последние
                         сообщения). Добавляет в Chat собеседника уведомление, которое будет выводиться со списком переписок;
      User openChat() со стороны активного пользователя находит переписку по никнейму. Если переписки с пользователем ещё нет, создаёт её и отправляет
                      ему первое сообщение. В случае успеха возвращает Chat, в который дальше можно отправлять сообщения;
      Server loginSequence() входит в аккаунт - ищет логин, проверяет пароль, в случае успеха возвращает User пользователя, от лица которого
                             можно выбирать переписки;
      Server registrationSequence() регистрирует нового пользователя по введённому логину, никнейму и паролю. Проверяет, есть ли уже такие логин и
                                    никнейм, проверяет их минимальную длину, проверяет минимальную длину пароля. В случае успеха добавляет нового
                                    пользователя.
